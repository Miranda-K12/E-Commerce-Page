# Full-E-Commerce-Website

This project is designed as part of the first step final project of the course "Woman in AI" at Business and Technology University. It serves as an e-commerce website that is responsive, with various features for showcasing and interacting with products. The website is developed using HTML, CSS, and modern front-end technologies, including CSS Grid, Flexbox, hover effects, and responsive breakpoints to ensure a smooth experience across devices.

## Overview

The Full E-Commerce Website project includes three main pages:

1. **Home**: The landing page where users can browse different products.
2. **About**: A page that provides details about the e-commerce website and its purpose.
3. **Wishlist**: A page where users can explore products they have added to their wishlist.

### Key Features:
- **HTML**: The website's structure and content are built using HTML5 to ensure semantic and accessible code.
- **Responsive Design**: The website is designed to be fully responsive, with specific breakpoints set for 1440px (desktop), 1024px, 768px, and 480px (mobile devices).
- **Flexbox & Grid Layouts**: Both Flexbox and CSS Grid are used for the layout, ensuring that the website adapts efficiently to different screen sizes.
- **Hover Effects**: Interactive hover effects are applied to elements, enhancing the user experience.
- **Bootstrap**: Bootstrap is used for the sidebar and breadcrumb components, making it easier to organize and navigate through different sections of the website.

This project was created to showcase practical skills learned in front-end development, focusing on creating a user-friendly and aesthetically pleasing e-commerce experience.
